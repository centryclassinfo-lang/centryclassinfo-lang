## Sobre nosotros

CentryClass es una plataforma peruana de capacitación técnica para ingenieros geólogos,
geotécnicos, geofísicos, hidrogeólogos, civiles y de minas. Nuestros docentes trabajan
en consultoras y laboratorios del sector, y enseñan lo que aplican en proyectos reales:
desde la ejecución de ensayos hasta el modelamiento y la toma de decisiones de diseño.

Ofrecemos cursos en vivo y grabados, además de programas de especialización que agrupan
varios cursos en una ruta de aprendizaje.

## Áreas de formación

| Área | Enfoque |
|------|---------|
| **Geotecnia** | Ensayos in-situ y de laboratorio, caracterización de suelos y rocas, presas de relaves |
| **Geomecánica** | Clasificación del macizo rocoso, estabilidad de excavaciones, sostenimiento en minería subterránea |
| **Geofísica** | Refracción sísmica, sondaje eléctrico vertical, tomografía eléctrica |
| **Hidrogeología** | Evaluación de contaminación de acuíferos, protección y remediación |
| **Modelamiento numérico** | Mecánica de suelos avanzada y métodos de diferencias finitas |
| **Programación aplicada** | Python para resolver, automatizar y visualizar problemas geotécnicos |

## ¿Qué encontrarás en este GitHub?

Este espacio reúne material técnico abierto que acompaña nuestra formación:

- Scripts y notebooks de Python aplicados a geotecnia y geología
- Plantillas de cálculo y procesamiento de datos de ensayos
- Ejemplos prácticos usados en clase

Puedes usarlos, adaptarlos y proponer mejoras mediante *issues* o *pull requests*.
